# M.V.P. — Analista NBA (web estática)

Web estática que muestra el contenido generado por el pipeline M.V.P.: quiz de la
jornada, resultados + análisis y la pieza contrafactual, con toggle
con-resultados / sin-spoilers. Los datos están en `data/` y toda la lógica corre
en el navegador. El código completo (pipeline, backend, scheduler) está en el
repositorio de GitHub.
